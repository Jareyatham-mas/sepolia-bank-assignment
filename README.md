# Sepolia Bank - Week 6

The Week 6 Bank DApp is published at [Sepolia Bank on GitHub Pages](https://jareyatham-mas.github.io/sepolia-bank-assignment/). The site connects to MetaMask on Sepolia and supports depositing, withdrawing, and checking the connected wallet's balance in the Bank contract.

The Solidity source files are `Lab3_Primitives.sol`, `Lab4_Sales.sol`, `Lab5_Systems.sol`, `Assignment4.sol`, and `Bank.sol`. The Bank contract is deployed on Sepolia at `0xd7C4B883481c901A7a61004391e92971f4B20843`.

Student name and ID are shown on the public page as authorized by the student. The page never asks for seed phrases or private keys. Wallet transactions require explicit MetaMask confirmation.
