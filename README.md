# Sepolia Bank - Assignment 5

This is the GitHub Pages-ready site for Lab 7. Publish this folder from the repository root (or copy its contents to the repository root), then enable GitHub Pages from the `main` branch and `/ (root)`.

The `contracts/` folder includes the Solidity source files for Labs 3-7. The Bank contract is deployed on Sepolia at `0xd7C4B883481c901A7a61004391e92971f4B20843`.

Student name and ID are shown on the public page as authorized by the student. The page never asks for seed phrases or private keys. Wallet transactions require explicit MetaMask confirmation.
